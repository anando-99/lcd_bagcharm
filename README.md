# Larp Charm

Web app for the Larp Charm — a bag charm built on the Waveshare ESP32-S3-Touch-LCD-1.69.

Open the live page in **Chrome on Android** (or Chrome/Edge on a computer), tap **Connect**, and pick **Larp Charm**.

## What it does
- Switch screens: Clock, Text, Photo, Clips, Music, Pet, Card
- Send text, photos, and long **GIFs and videos** (converted to MJPEG on your phone, stored on the charm, up to ~9.9 MB)
- Spotify now-playing with album art, or type a song in manually (YouTube Music etc.)
- Pet, name card and NFC tag writer
- Brightness, sleep timer, swipe direction

Needs charm firmware **2.0** or newer.
